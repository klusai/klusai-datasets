# Tranche 2: diagnosis and frozen changes

The earlier 300-document judgments identify these five causes (overlapping counts):

1. **Forced aliases/repetition (139/300):** name-only quoted lines served the feature counter,
   not the user's task. Replace them with real greetings, quoted replies and signatures;
   only record aliases/repetition when those actual mentions occur.
2. **Unmotivated people / PII density (107/300; another 47 short name lists):** names had
   no role, and sensitive fields did not fit the workflow. Give each person a concrete
   ticket, expense, candidate, appointment, access event or passenger record. Put dense
   cases in medium/long messages; national IDs belong to intake/onboarding, not travel.
3. **Benchmark-like negatives (56/300):** prose explicitly explained what was not PII.
   Replace it with actual requests about public documentation, history, product data,
   statutory references, forms and executable code. No annotation-policy coaching.
4. **Generic long correspondence (53/300; 25 mismatched negative contexts):** reused
   portal prose supplied length without information. Long messages now carry accounting
   exports or executable reproduction code with concrete inputs and expected outcomes.
5. **Under-specified tasks / stiff stock register (25–29/300):** code questions lacked
   code, CV requests lacked skills and every language followed the same formal setup.
   Use shorter idiomatic asks, multiple openings and task-specific source material.
